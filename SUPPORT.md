# Support

For usage questions, open a GitHub issue with the question and a minimal synthetic
configuration. For a reproducible bug or feature request, use the corresponding
template. Read the workspace, browser, and compatibility guides first.

Include the AgentQit version, operating system, Python version, installation method,
expected behavior, and redacted output. Use synthetic IDs and reserved example
addresses. Keep credentials, authenticated browser state, and private traces local.

Security vulnerabilities must use the private reporting route in [SECURITY.md](SECURITY.md).
Support is provided by maintainers and contributors as time allows; there is no
support SLA. Follow the [community guidelines](CODE_OF_CONDUCT.md).
